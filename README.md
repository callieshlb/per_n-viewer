# Per_9(0): the computation behind the model

Scripts and data that produce the uniformized model of Per_9(0) shown in the
[Per_n(0) atlas](https://callieshlb.github.io/per_n-viewer/). This branch is not part of the website (the website is the
`main` branch). `METHODS.md` describes the steps, the checks and their results, and the known limitations.

## Layout

- `per9/` — the curve (`per9_xy_poly.txt`), branch points and monodromy (`branch.json`), mesh radii at the nodes (`nodes.json`), the root tracker (`trackmp.py`, used
  by `make_centres.py` and `explorer/build_data9.py`), the gluing helper (`cutglue.py`), shared code (`options_probe_lib.py`), and the punctures (`puncture_place.py` ->
  `puncture_place.json`, `puncture_markers.py`).
- `per9/explorer/` — `build_data9.py` -> `data.json` (centers, punctures, coefficients); `per9_core.js` (double-precision dynamics used by the viewer).
- `per9/surface3d/` — mesh, gluing, uniformization, development, charts, overlays: scripts and data (list below).
- `inputs/` — files computed earlier: the census of centers, punctures and real-circle arcs with its helper module (`E90-real-circles/`), and the graph G_9 (`E95-probe/`).

## Order (run in `per9/surface3d/` unless noted)

1. `per9/make_centres.py`; `per9/explorer/build_data9.py` -> `explorer/data.json`
2. `make_sphere_mesh.py fine` -> `sphere_mesh.json`
3. `glue.py`, then `assemble.py` -> `surface_mesh.json`, `edge_perms.json` (not included: 280 MB and 56 MB; these two steps take 1-2 minutes)
4. `uniformize.py` -> `uniform_u.npy`; `refine.py` -> `refine_ckpt.npz` (160-bit u = hi + lo)
5. `develop.py` -> `develop.npz` (included in 3 parts in `develop_parts/`; join with `cat develop_parts/develop.npz.part0* > develop.npz` and compare with `SHA256SUMS`)
6. `fold_vertices9.py`; `vertex_x.py`, `vertex_x_polish.py`, `vertex_x_finish.py`, `vertex_x_inner.py` -> `vertex_x.npz` (not included, 130 MB)
7. `chart_export9.py` -> `chart_grids_*.bin`, `chart_meta.json`, `chart_map.png`; `pack_grids9.py` -> `chart_grids_0..4.dxs` (the raw `.bin` parts are not included: the `.dxs` parts are lossless)
8. `conformal_export9.py` -> `conformal_data.js`; `marker_info9.py` -> `marker_info.json`
9. `per9/puncture_place.py` -> `puncture_place.json`; `per9/puncture_markers.py` (adds the punctures to `explorer/data.json`, `conformal_data.js`, `marker_info.json`)
10. `g9_edges.py`, `trace_ovals.py` -> `oval_points.json`, `oval_check9.py` -> `run7/oval_check.json`, then `OVALS=0,3,4,5 oval_export9.py run7/...` -> `overlay_data.json`

`meshloc.py` (locating a point of the curve in the mesh and the disk), `fuchs.py` (group and Dirichlet polygon code), `oval_check.py` and `overlay_export_lib.py`
are helpers imported by the scripts above. The files the site loads are `conformal_data.js`, `chart_grids_0..4.dxs`, `chart_meta.json`, `chart_map.png`,
`overlay_data.json`, `marker_info.json` and `explorer/data.json`.

## Notes

- Not included because of size: `surface_mesh.json`, `edge_perms.json` (regenerated by step 3), `vertex_x.npz` and the folded vertex positions (step 6), the
  real-circle lifts `run7/oval_lifts.npz`, the coarse mesh and the convergence scripts.
- E90, E95 in names are internal run numbers: E90 = the census, E95 = this computation (and its earlier probe).
- Seven paths were changed so the scripts find `inputs/` in this layout, and three comments were edited. The pipeline was not re-run after these changes.
- Requirements: Python with numpy, scipy, pyamg, sympy, mpmath, gmpy2, python-flint, Pillow.
- Three files are larger than 50 MB (two parts of `develop.npz` and `refine_ckpt.npz`); all are below GitHub's 100 MB limit.
