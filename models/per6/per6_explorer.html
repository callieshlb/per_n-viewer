What is drawn

Each view of parameter space is one branch of x(y) continued from the view centre along straight segments (rounding the node at y = 0), so a view is a chart of Per6(0). Branch cuts appear as rays from branch points (×) pointing away from the view centre. "Sheet" is the atlas label (continuation from the fixed base point y0), shown for the view centre; panning keeps you on the same local branch.

Colour = fate of the free critical point ω = 2xw/(x+w): captured by the marked cycle (hue = phase: the component Uj of the marked cycle whose basin contains ω), attracted to another cycle (greys), or undecided (black: bifurcation locus). Dark red: the branch could not be continued (at a branch point).

Markers: white dots = the 27 polynomial centres (even numerator /63); red squares = the 18 punctures; × = branch points; ○ = the node at y = 0. A marker is drawn only when it lies on the branch being shown. Punctures over y = 1 sit at x = ∞ where two sheets meet, so their sheet is a convention.
