What is drawn

Each view of parameter space is one branch of x(y) continued from the view center along straight segments (rounding the node at y = 0), so a view is a chart of Per7(0). Within |y| < ~0.35 of the node, ten branches are tangent to order 4 and double precision cannot follow them: such pixels are drawn dark red rather than risk the wrong branch. Branch cuts appear as rays from branch points (×) pointing away from the view center. "Sheet" is the atlas label (continuation from the fixed base point y0), shown for the view center; panning keeps you on the same local branch.

Color = fate of the free critical point ω = 2xw/(x+w): captured by the marked cycle (hue = phase: the component Uj of the marked cycle whose basin contains ω), attracted to another cycle (greys), or undecided (black: bifurcation locus). Dark red: the branch could not be continued (at a branch point).

Markers: white dots = the 63 polynomial centers (even numerator /127); red squares = the 40 punctures; × = branch points; ○ = the node at y = 0 and the four points where one root goes to x = ∞. A marker is drawn only when it lies on the branch being shown. Punctures over y = 1 sit at x = ∞ where two sheets meet, so their sheet is a convention.
